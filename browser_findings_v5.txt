1. site_title = "WALK CONTAS DE APP" está no banco e APARECE corretamente na página
2. Os features (feature1_title, etc.) estão VAZIOS no banco, então usam o default
3. O usuário provavelmente editou os campos no admin mas eles não foram salvos, OU
   ele espera que ao editar "site_title" os features mudem também

POSSÍVEL PROBLEMA:
- O usuário pode ter digitado novos valores nos campos do admin mas não clicou no botão salvar (ícone de disquete) de cada campo
- Cada campo tem seu próprio botão de salvar individual

SOLUÇÃO:
- Adicionar um botão "Salvar Tudo" que salva todos os campos de uma vez
- Ou verificar se o botão de salvar individual está funcionando corretamente
