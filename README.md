# H2 AUTO — Menu de cards independente

Página estática separada do site H2 Colombiano, publicada a partir desta ramificação isolada.
Não contém números reais de WhatsApp, segredos ou banco de dados.
O aplicativo Android adiciona o destino usando o fragmento de URL `#to=55DDDNUMERO`.
O cliente deve confirmar manualmente o envio de cada opção no WhatsApp.
Esta ramificação não deve substituir o site de produção do repositório.
